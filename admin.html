Přihlášení do administrace

Zadejte váš GitHub Personal Access Token pro přístup k repozitáři gratusapp/gratusapp.

Jak získat token za 1 minutu:
1. Přejděte na Vytvoření nového tokenu na GitHubu.
2. Zaškrtněte oprávnění repo (plný přístup k repozitářům).
3. Klikněte dole na Generate token a zkopírujte ho sem.
Token zůstává bezpečně uložen pouze ve vašem lokálním prohlížeči (localStorage).
